Authorized 2026-10-18. Isolated experiment under /workspace/Cell-Free-DT-new/experiments/preference_prompt_v1; no existing project source or formal models overwritten.

Six local actors and critics already uploaded to results/weights/B1000_pc_sweep. All 12 SHA256 values were checked against local final checkpoints. Use four teachers: pc0.6,1.5,1.8,2.1; each trained from scratch with QoS80/.2/.2 and its own pc weight. Collect matched seed1..5, 10080 steps each:20 environment trajectories=320 AP trajectories. B1000,16AP250m, neighbor.25km,cluster.90,min1. Deterministic source policy. In every rollout calculate rewards with COMMON40/.5/.5/3, not the teacher's training reward; save teacher preference and actor hash separately. Independent compressed list-of-five PKLs per teacher, never shared concurrent writes or raw duplicate files.

Train only on these new20 episodes, not on all332 old seven-environment episodes. PDT and DT share the original backbone, data and training budget: context8,3blocks128dim1head,dropout.1,batch256,lr5e-4,weight_decay1e-4,seed1,workers4,1800rounds*150updates,rtg_scale1,no observation normalization. Continuous scalar preference token pc/2.5 for PDT. DT has no prompt token. Backbone initialization is identical; PDT has a small additional scalar projection, so this is not exact parameter-count matching. This tests preference-conditioned imitation, NOT improvement of the old deployment prompt or unseen-scenario generalization.

Evaluate unseen seeds6..10, full7days: PDT at four training preference values plus one DT,25rollouts. All use the SAME raw RTG target, computed before evaluation as mean per-AP episode return over the20training trajectories. No RTG search. The same scalar target across all preferences isolates preference choice but may be off-support for some preferences; report group return ranges. Fixed-context prompt-sensitivity diagnostic is on sampled TRAINING contexts and is only a mechanistic check, not held-out generalization evidence. Compare final drop using pooled UE packet counts by delay_budget.05/.15/.3 and power reward.csv pc_kw. Existing teacher simulation seed1..5 must NOT be presented as a matched-seed comparison to heldout6..10.
